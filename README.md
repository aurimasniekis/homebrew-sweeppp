# Homebrew tap for Sweep++

```bash
brew install aurimasniekis/sweeppp/sweeppp          # or aurimasniekis/sweeppp/sweeppp-nightly
```

The casks are rewritten by CI in [aurimasniekis/sweeppp](https://github.com/aurimasniekis/sweeppp)
after every build; do not edit them here.

[sweeppp.app](https://sweeppp.app)
